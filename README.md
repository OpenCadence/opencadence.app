# OpenCadence website

The open-source marketing website for [OpenCadence](https://opencadence.app), an open-source workspace for freelancers.

This repository contains the public website only. The Community application lives in the [OpenCadence repository](https://github.com/OpenCadence/opencadence).

## Explore OpenCadence
